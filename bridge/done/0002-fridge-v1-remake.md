# 냉장고 숏츠 v1 고화질 재제작

## 배경
냉장고 정리 숏츠 v1(19.6초, 1080×1920, 30fps)이 완성됐고 사용자가 OK했지만, 화질이 나쁘다는 지적을 받았다. 원본이 인스타그램 다운로드본이라 재인코딩 과정에서 화질이 깨졌다. 회의실의 클로드는 PC 폴더가 필요해서 재제작이 불가하다고 했다. 이제 PC의 Claude Code가 직접 재제작한다.

## 원본 자료
- v1 영상: https://drive.google.com/file/d/1L-t2zxcpVwJrmWxRyOhlhwTBUO7kFuv4/view (fridge_organizer_shorts_v1.mp4)
- Drive 폴더: https://drive.google.com/drive/folders/1Wq8R0MdC88M-pSOcOtV0rcTf80FiDAWs
- 소스 영상 9개가 Drive에 있다(피클5가 업로드). 승인된 소스 4개: @caitliniola(메인, 4,418만 조회), @sam.shan.shops, @iamerineller, @torilanaee
- 자막·후킹 3안·썸네일 문구·캡션·해시태그·유튜브 제목(KR·JP): https://app.notion.com/p/424e6e18da868159b79cf551e9ca3a76

## 할 일
1. v1과 소스 영상을 확인하고, 가능한 가장 고화질로 냉장고 정리 숏츠 v1을 다시 만든다.
2. 목표: 1080×1920, 30fps, 화질 깨짐 최소화(ffmpeg CRF 16~18, 단일 인코딩, lanczos 스케일링).
3. v1과 같은 구성(19.6초, 11컷)을 유지한다.
4. 완성본을 PC 적당한 폴더에 저장하고, 저장 위치를 결과에 적는다. Drive 업로드가 가능하면 Drive에도 올리고 링크를 적는다.

## 참고
- Drive 파일에 직접 접근이 안 되면, 결과에 그 사실을 적고 사용자가 PC 폴더에 파일을 내려받아 두면 된다고 안내한다. 무리하게 진행하지 않는다.

## 결과 보고
- 결과 파일에 완성본 위치, 사용한 화질 설정, v1보다 나아진 점을 적는다.
- 소스 자체 화질이 낮아서 더 이상 개선이 안 되면, 원인과 대안을 적는다.
